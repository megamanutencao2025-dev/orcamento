Quero que este projeto seja desenvolvido com uma arquitetura profissional, organizada e escalável.

### Backend

* Utilizar *Python* como linguagem principal do backend (preferencialmente com Django ou Flask, conforme a necessidade do projeto).
* O Python deve ser responsável por toda a lógica de negócio, autenticação, acesso ao banco de dados, APIs, processamento e regras do sistema.
* O código deve seguir boas práticas (PEP 8), ser modular, reutilizável e bem documentado.

### Frontend

* Utilizar *HTML5, **CSS3* e *JavaScript* trabalhando em conjunto com o backend em Python.
* O JavaScript deve ser responsável pela interatividade da interface, requisições assíncronas (AJAX/Fetch), atualizações dinâmicas e melhorias na experiência do usuário.
* Sempre que possível, evitar recarregar páginas desnecessariamente.

### HTML

* Criar um HTML semântico, limpo e bem estruturado.
* Utilizar elementos apropriados (header, main, section, article, footer, etc.).
* O código deve ser de fácil manutenção e leitura.

### CSS

* O CSS deve ser organizado em arquivos separados por responsabilidade.
* Utilizar nomes de classes padronizados e consistentes.
* Evitar duplicação de estilos.
* Criar uma interface moderna, intuitiva e responsiva.
* Manter uma identidade visual consistente em todas as páginas.
* Utilizar variáveis CSS para cores, fontes, espaçamentos e tamanhos.
* Sempre priorizar a organização e a facilidade de manutenção.

### JavaScript

* Organizar o código em módulos ou arquivos separados por funcionalidade.
* Evitar funções muito grandes.
* Comentar apenas quando realmente necessário.
* Escrever código limpo e reutilizável.

### Estrutura do Projeto

Organizar os arquivos de forma lógica, por exemplo:

* backend/
* frontend/

  * html/
  * css/
  * js/
* templates/
* static/
* media/
* database/
* docs/

### Qualidade do Código

* Evitar código repetido.
* Priorizar desempenho e legibilidade.
* Pensar na escalabilidade desde o início.
* Sempre que houver mais de uma forma de implementar uma funcionalidade, escolher a solução mais organizada, segura e fácil de manter.

Antes de criar qualquer funcionalidade, analisar se ela se encaixa na arquitetura do projeto, mantendo o padrão de organização em todas as etapas do desenvolvimento.
